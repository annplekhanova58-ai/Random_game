# Журнал прототипа

## Итерация 1

- Граница цены ровно 0 больше не возвращает пустой каталог. Игры с ценой 0 участвуют в розыгрыше, когда граница их покрывает, включая 0.
- На экране `/` добавлен переключатель «Только бесплатные» / Free only. Состояние хранится в `localStorage` (`rsg-free-only`) рядом с сохранённой ценой (`rsg-max-price`).
- Включённый переключатель оставляет только игры с `priceUsd === 0`, не читает поле цены и отключает его. Выключенный оставляет прежнюю границу, и бесплатные игры входят, если не дороже границы.
- В макет добавлены бесплатные игры с локальными SVG-обложками: Dota 2 (570), Team Fortress 2 (440), Warframe (230410), Apex Legends (1172470), Path of Exile (238960). Counter-Strike 2 (730) остаётся.
- Пустой каталог показывается только когда отфильтрованный пул действительно пуст. Для режима «только бесплатные» отдельный текст, без совета поднять цену.
- Исключение истории по-прежнему действует на бесплатные игры.
