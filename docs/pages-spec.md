# Экраны — Случайная игра Steam

| Route | Page | Functionality | Roles |
|-------|------|---------------|-------|
| /sign-in | Вход | Email, пароль, ошибка входа, переход к регистрации, переключатель языка | Гость |
| /register | Регистрация | Email, пароль, создание аккаунта, переход ко входу, переключатель языка | Гость |
| / | Бросок | Верхняя граница цены, кнопка «случайная игра», карточка одной игры (название, описание, цена, обложка, ссылка на Steam), сообщение «нет подходящих игр», ошибка Steam и повтор, выход, переключатель языка | Пользователь |
| /history | История | Список уже выпавших игр со ссылками на Steam, удаление одной записи, очистка всей истории | Пользователь |
