# Требования — Случайная игра Steam

Рабочее имя продукта: **«Случайная игра Steam»**. В английской локали окна — **Random Steam Game**. Имя можно заменить позже, поведение от этого не меняется.

## Обзор

Локальная программа на компьютере владельца выбирает одну случайную игру из витрины Steam. Один розыгрыш показывает ровно одну игру: на экране крутятся обложки и останавливаются на выбранной, затем открывается карточка со ссылкой на страницу игры в Steam.

Продукт нужен одному человеку — владельцу этого компьютера. Личная библиотека Steam, вход в аккаунт, покупка внутри программы, уведомления, отчёты и админка в первую версию не входят.

Источник каталога — публичная витрина Steam. История показов и настройки хранятся на этом компьютере, чтобы уже показанная игра не выпала снова.

### Первая версия

- Отдельное окно и запуск ярлыком с рабочего стола.
- Верхняя граница цены в USD, задаёт владелец.
- Переключатель «Только бесплатные»: в выборке остаются игры с ценой 0, граница цены в этот момент не применяется.
- Один розыгрыш — одна уже вышедшая игра, затем визуальная рулетка.
- Карточка результата и ссылка на страницу игры в Steam.
- Локальная история с просмотром и удалением записей.
- Интерфейс на русском и английском.

### Вне первой версии

- Жанры, метки и кооператив.
- Список из нескольких победителей за один розыгрыш.
- Выбор из личной библиотеки Steam.
- Покупка и оплата внутри приложения.
- Конвертация валют и цены не в USD.
- Регистрация, вход, аккаунт и приглашения.
- Уведомления, отчёты, журнал аудита и админка.
- Телефонная вёрстка и публичный сайт.
- Фильтр по возрасту: игры 18+ остаются в выборке.

## Роли пользователей

Роль одна. Учётной записи нет, поэтому отдельных прав «гость» и «администратор» нет.

| Роль | Кто это | Как попадает в программу |
|------|---------|--------------------------|
| Владелец компьютера | Единственный человек, который работает за этим компьютером | Открывает окно ярлыком. Вход и регистрация не требуются |

### Права владельца компьютера

| Действие | Доступ |
|----------|--------|
| Задать и изменить верхнюю границу цены в USD | Да |
| Включить и выключить «Только бесплатные» | Да |
| Запустить розыгрыш | Да |
| Смотреть рулетку и карточку результата | Да |
| Открыть страницу выбранной игры в Steam | Да |
| Открыть историю показов | Да |
| Удалить одну запись истории | Да |
| Удалить всю историю | Да |
| Переключить язык интерфейса | Да |

Других ролей нет. Чужой человек за этим же компьютером действует как тот же владелец: данные локальные и общие для установки на этом компьютере.

## Сущности

Три агрегата. Программа читает витрину Steam на время розыгрыша и не хранит у себя весь каталог. Пользователь как хранимая сущность отсутствует.

| Агрегат | Смысловая граница | Где хранится | Операции | Экраны |
|---------|-------------------|--------------|----------|--------|
| Игра витрины | Публичный каталог Steam | Внешняя витрина; локальный каталог не ведётся | Только чтение | `/`, `/result` |
| Запись розыгрыша | Уже показанные игры | Локально на этом компьютере | Создание, чтение, удаление | `/result`, `/history` |
| Локальные настройки | Граница цены и язык | Локально, одна запись на компьютер | Создание, чтение, изменение | `/` (цена), оболочка окна (язык) |

У записи розыгрыша нет изменения: снимок на момент розыгрыша остаётся как есть. У локальных настроек нет удаления: смена цены или языка обновляет ту же запись. У игры витрины нет локального создания и удаления.

### Игра витрины

Только чтение публичных данных Steam на время розыгрыша.

| Данные | Смысл |
|--------|--------|
| `steam_app_id` | Постоянный идентификатор позиции в Steam |
| Название | Как его отдаёт витрина, без перевода приложением |
| Обложка | Изображение для рулетки и карточки |
| Текущая цена USD | Цена, по которой игру можно взять сейчас; `0` — бесплатная |
| Ссылка на страницу | Адрес страницы этой игры в Steam |
| Признак выхода | Уже вышла, включая ранний доступ, либо ещё нет |

Связь: запись розыгрыша ссылается на игру по `steam_app_id`. Игры между собой не связаны.

### Запись розыгрыша

Создаётся при успешном розыгрыше. Читается в истории и при сборке следующей выборки. Удаляется по одной или все сразу.

| Данные | Смысл |
|--------|--------|
| Локальный идентификатор | Ключ записи на этом компьютере |
| `steam_app_id` | Игра, которую исключают из следующих розыгрышей |
| Название, обложка, ссылка | Снимок для истории, если витрина позже недоступна |
| Цена USD | Цена на момент розыгрыша |
| Момент розыгрыша | Локальные дата и время компьютера |

Связи: много записей на один компьютер; не больше одной действующей записи на один `steam_app_id`. Пока запись есть, эта игра в выборку не входит.

Удаление физическое. Отдельного архива, корзины и мягкого удаления нет. Удаление записи не меняет данные в Steam.

### Локальные настройки

Одна запись на компьютер. Создаётся при первом запуске.

| Данные | Смысл |
|--------|--------|
| Верхняя граница цены USD | Пусто, пока владелец её не задаст. После ввода хранится, пока её не изменят |
| Только бесплатные | Включено или выключено. По умолчанию выключено. Хранится вместе с границей цены |
| Язык интерфейса | `ru` или `en` |

Связь: одна запись настроек на эту установку. Список розыгрышей в неё не входит. Граница цены только ограничивает выборку.

## Бизнес-правила

### Главный сценарий

1. Владелец запускает программу ярлыком. Открывается окно на экране рулетки.
2. Он задаёт верхнюю границу цены в USD либо оставляет уже сохранённую. При необходимости включает «Только бесплатные».
3. Он запускает розыгрыш. Программа читает витрину Steam и локальную историю.
4. Из подходящих игр выбирается ровно одна, с равной вероятностью среди оставшихся.
5. Запись сохраняется локально.
6. На экране крутятся обложки и останавливаются на обложке выбранной игры.
7. Открывается карточка и ссылка на страницу игры в Steam.
8. Окно остаётся открытым. Следующий розыгрыш начинается только по новому действию владельца.

Рулетка показывает уже сделанный выбор. Она не является вторым жребием и не объявляет несколько победителей.

### Какие игры входят в выборку

В один розыгрыш попадает позиция витрины, которая одновременно:

- является игрой;
- уже вышла, включая ранний доступ;
- имеет текущую цену в USD;
- стоит не дороже заданной границы (сравнение включительно);
- ещё не числится в локальной истории.

Текущая цена — та, по которой игра предлагается сейчас. Если на витрине действует скидка, берётся цена со скидкой. Бесплатная игра имеет цену `0` и входит в выборку, когда граница её покрывает, в том числе когда граница равна `0`. Любая сохранённая граница неотрицательна, поэтому при выключенном переключателе бесплатные игры входят при любой допустимой границе.

Если включён переключатель «Только бесплатные», граница цены не применяется: в выборке остаются только игры с ценой `0`, которых ещё нет в истории. Поле цены на это время не редактируется. Состояние переключателя сохраняется на этом компьютере.

Игры 18+ входят в выборку наравне с остальными. Отдельной пометки возраста на карточке нет.

В выборку не входят дополнения, саундтреки, видео, демо, наборы, программы и другое, что не является игрой. Не входят ещё не вышедшие игры, в том числе предзаказ до релиза. Не входят позиции без цены в USD: курс программа не пересчитывает. Не входят игры, для которых уже есть запись истории.

### Граница цены

- Граница — неотрицательное число в USD. Дробная часть допустима.
- При пустом, отрицательном или нечисловом значении розыгрыш не запускается. Программа просит ввести неотрицательную цену в USD.
- В русской локали допустимы запятая и точка как разделитель дробной части.
- Заданная граница сохраняется на этом компьютере и подставляется при следующем запуске.
- Во время кручения рулетки границу изменить нельзя.

### Рулетка и результат

- После успешного выбора программа показывает анимацию обложек. Анимация заметна и заканчивается остановкой на обложке выбранной игры. Затем открывается экран результата.
- Обложки в ленте берутся из той же подходящей выборки. Если подходящая игра одна, лента всё равно останавливается на её обложке.
- Карточка показывает обложку, название, цену в USD на момент розыгрыша и ссылку на страницу игры. Для цены `0` подпись означает бесплатную игру на языке интерфейса.
- Ссылка открывает страницу игры в браузере системы. Окно программы остаётся открытым. Покупка проходит на стороне Steam.
- Пока рулетка крутится, переходы к истории и новому розыгрышу ждут остановки.

### История

- Запись пишется после выбора игры и до следующего розыгрыша. Если окно закрыть во время анимации, игра уже считается показанной.
- Если запись не удалось сохранить, розыгрыш не завершается: карточка не открывается, игра не считается показанной, программа сообщает об ошибке записи.
- История открывается списком от новых показов к старым. В строке те же сведения, что на карточке, плюс дата и время.
- Удаление одной записи сразу убирает её и снова допускает эту игру к выбору.
- Удаление всей истории спрашивает подтверждение. После подтверждения все записи удаляются, и показанные игры снова допускаются к выбору.
- Пока в истории есть `steam_app_id`, новый розыгрыш его не выбирает.

### Пустая выборка и сбой Steam

- Если подходящих игр не осталось, программа сообщает об этом понятным текстом. При выключенном переключателе подсказка — поднять границу или очистить историю. При включённом — выключить «Только бесплатные» или очистить историю. Запись истории не создаётся.
- Если витрина Steam недоступна, программа показывает ошибку и действие «повторить». Повтор использует ту же границу. Запись истории не создаётся.
- Повтор после ошибки и новый розыгрыш после результата — разные действия. Новый розыгрыш сам не стартует.

### Зафиксированные решения

Эти правила приняты по ответам и рабочим решениям первой версии:

| Тема | Решение |
|------|---------|
| Сколько игр за розыгрыш | Ровно одна. В том же окне можно запустить следующий розыгрыш отдельно |
| Какая цена | Текущая цена витрины в USD, со скидкой, если скидка действует |
| Бесплатные | Цена `0`. Входят, если граница их покрывает. Переключатель «Только бесплатные» оставляет только их |
| Ранний доступ | Считается уже вышедшей игрой |
| 18+ | Остаются в выборке |
| Дополнения и не-игры | В выборку не входят |
| Повтор показа | Исключение действует, пока жива локальная запись |
| Удаление | Физическое; возвращает игры в выборку |
| Язык при первом запуске | Язык ОС, если он русский или английский; иначе русский |

## Интеграции

| Система | Зачем | Поток данных | Учётные данные |
|---------|-------|--------------|----------------|
| Витрина Steam | Каталог, текущая цена в USD, обложка, признак выхода, ссылка на страницу игры | Только чтение публичных данных | Не запрашиваются и не хранятся |
| Браузер операционной системы | Открыть страницу игры | Переход по ссылке из карточки или истории | Не используются |
| Рабочий стол | Ярлык и отдельное окно | Запуск программы | Не используются |
| Локальное хранилище компьютера | История и настройки | Запись и чтение только на этом компьютере | Не используются |

Импорт и экспорт файлов, почта, платежи, облачное хранилище и сервер продукта для пользовательских данных не входят в первую версию. Программа не входит в аккаунт Steam и не читает библиотеку владельца.

## Нефункциональные требования

### Масштаб

- Один компьютер и один человек.
- Одновременной работы нескольких пользователей нет.
- Синхронизации между компьютерами нет.
- Каждый успешный розыгрыш добавляет одну локальную запись.
- История растёт только за счёт этих записей и уменьшается удалением.

### Языки

- Все тексты интерфейса, подписи, кнопки и сообщения есть на русском и английском.
- Переключатель языка находится в оболочке окна и доступен на каждом экране.
- Выбранный язык сохраняется локально и применяется при следующем запуске.
- Первый запуск берёт язык ОС, если это русский или английский. Иначе язык русский, пока владелец его не сменит.
- Названия игр приложение не переводит. Обложки и цены приходят из Steam.
- Даты в истории показываются в локальном часовом поясе компьютера и на языке интерфейса.

### Безопасность

- Входа, регистрации, пароля приложения и ролей кроме владельца компьютера нет.
- Программа не запрашивает и не сохраняет пароль Steam, платёжные данные и данные банковской карты.
- Чтение витрины ограничено публичными сведениями каталога.
- История и настройки остаются на этом компьютере и не отправляются на сервер продукта.
- Удаление истории удаляет локальные записи и ничего не меняет в аккаунте Steam, потому что аккаунт не подключён.

### Окно

- Программа работает в отдельном окне операционной системы.
- Макет рассчитан на это окно. Отдельная телефонная вёрстка не требуется.
- Публичный сайт в интернете не требуется.
- При запуске открывается экран рулетки.
- Окно остаётся открытым после результата, ошибки Steam и пустой выборки.

### Ярлык

- Программу запускают ярлыком на рабочем столе.
- Ярлык открывает окно на экране рулетки.

### Доступность функций без сети

- Новый розыгрыш требует доступную витрину Steam.
- История, смена языка и правка границы цены работают без связи со Steam.
- Если обложка в истории не загрузилась, строка всё равно показывает название, цену, дату и ссылку.
