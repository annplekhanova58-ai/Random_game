# Требования — Случайная игра Steam

Источник ответов заказчика. Рабочее имя временное: название продукта сейчас не важно.

## Overview

Личный инструмент выбирает одну случайную игру из витрины Steam. Пользователь задаёт верхнюю границу цены, получает карточку игры и ссылку на её страницу в Steam. Уже выпавшие игры сохраняются и больше не предлагаются, пока их не уберут из истории.

Первая версия — ровно этот сценарий. Отдельного списка «сделать потом» нет.

## User Roles

| Роль | Кто | Права |
|------|-----|--------|
| Гость | Человек без входа | Видит вход и регистрацию. Бросать игру и смотреть историю не может. |
| Пользователь | Владелец аккаунта | Входит, задаёт цену, бросает одну игру, открывает ссылку на Steam, смотрит историю, удаляет одну запись или всю историю, выходит, переключает язык. |

Администратора нет. Приглашений, SSO и входа через Steam нет. Audit log не нужен.

Пользователь продукта сейчас один. Регистрация всё равно нужна: история должна сохраняться между визитами.

## Core Entities

| Сущность | Обязательные поля | Связи | Операции |
|----------|-------------------|-------|----------|
| Аккаунт | email, пароль | 1 аккаунт — много записей истории | Создание, вход, выход. Редактирование профиля и удаление аккаунта не входят в первую версию. |
| Бросок / запись истории | игра Steam (id, название, цена, ссылка, обложка), момент броска | Принадлежит одному аккаунту | Создание при успешном броске, просмотр списка, удаление одной записи, очистка всего списка. Изменение записи нет. |
| Игра Steam | id, название, краткое описание, цена, обложка, дата выхода, возрастной рейтинг, ссылка на магазин | Только чтение из витрины Steam | В приложении не создаётся и не редактируется. |

Мягкого удаления нет: запись истории удаляется сразу. Справочник статусов не нужен.

## Business Rules

1. Один запрос возвращает ровно одну игру.
2. Источник — витрина Steam, не личная библиотека.
3. Пользователь задаёт верхнюю границу цены. Игра дороже этой границы не выпадает. Бесплатная игра допустима, если граница её покрывает. Цена сравнивается в USD, без конвертации.
4. Ещё не вышедшая игра не выпадает.
5. Игра с рейтингом 18+ не выпадает.
6. Игра, которая уже есть в истории этого пользователя, не выпадает.
7. Результат показывает название, краткое описание, цену, обложку (если Steam её отдал) и ссылку на страницу игры. Покупка внутри приложения не выполняется.
8. Если подходящих игр не осталось, показывается сообщение, а не пустой экран.
9. Если Steam недоступен, показывается ошибка и возможность повторить.
10. Удаление одной записи или всей истории снова допускает эти игры к случайному выбору.
11. Жанры, метки, кооператив, фильтр «ещё не играл» и список из нескольких игр не входят в первую версию.

## Integrations

- Публичный каталог Steam (Steam Web API или витрина магазина). Свой ключ пользователя не нужен.
- Уведомлений, отчётов, import/export и хранилища файлов нет.

## NFR

- Масштаб: один пользователь.
- Язык интерфейса: русский и английский, с переключателем.
- Телефонная вёрстка не требуется. Достаточно экрана компьютера.
- Пароль хранится только в виде хеша. Чужую историю видеть нельзя, потому что других ролей нет.
- Доступность сверх обычной клавиатуры и понятных подписей не задана.
- Офлайн-режим не нужен.
